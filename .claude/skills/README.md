# Скиллы проекта

Скиллы подключаются автоматически в любой сессии Claude Code на этом
репозитории. Ставить ничего не нужно, они лежат прямо здесь.

| Скилл | Что делает | Автор, лицензия |
|---|---|---|
| `stop-slop` | Убирает из текстов нейросетевой почерк: канцелярит, штампы, лишние наречия. Полезен для писем подопечным, описаний и лендинга. | [Hardik Pandya](https://github.com/hardikpandya/stop-slop), MIT |
| `ui-ux-pro-max` | База по интерфейсам: стили, палитры, пары шрифтов, UX-правила, графики, рекомендации под стек. Полезен при работе над дизайном приложения. | [nextlevelbuilder](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), MIT |
| `design-taste-frontend` | Дизайн без шаблонного вида: сначала читает задачу, потом выбирает направление. Для лендинга и промо-страниц. | [Leonxlnx](https://github.com/Leonxlnx/taste-skill), MIT |
| `redesign-existing-projects` | Аудит и переделка существующих экранов: находит типовые «нейросетевые» решения и заменяет их. | [Leonxlnx](https://github.com/Leonxlnx/taste-skill), MIT |
| `brandkit` | Фирменный стиль: логотип, палитра, гайдлайны. Пригодится, когда будем оформлять бренд FitTrainer. | [Leonxlnx](https://github.com/Leonxlnx/taste-skill), MIT |

В репозитории [taste-skill](https://github.com/Leonxlnx/taste-skill) есть ещё
несколько скиллов под конкретную эстетику (`brutalist`, `minimalist`, `soft`,
`stitch`, генерация изображений). Их можно добавить так же, скопировав папку
из `skills/` в `.claude/skills/`.

Обновить скилл: удалить его папку и склонировать заново с репозитория автора.
Лицензии авторов лежат внутри папок скиллов.
