# FitTrainer

Приложение для фитнес-тренеров и их подопечных.

Сейчас это прототип веб-приложения (React + Vite + TypeScript), собранный так,
чтобы позже без переписывания стать сайтом, PWA, webview-приложением или
мини-приложением Telegram / Max.

## Запуск

```bash
npm install
npm run dev
```

Открой `http://localhost:5173`. На десктопе приложение показывается внутри
мокапа iPhone. Без рамки: `http://localhost:5173/?frame=0`. На телефоне рамка
отключается автоматически.

## Что уже есть (роль тренера)

- **Расписание**: лента дней, тренировки на выбранный день и ближайшую неделю,
  отметка «проведена / пропуск / отменена», добавление разовых и еженедельных
  тренировок.
- **Подопечные**: список с остатком занятий и долгом, фильтры «заканчивается» и
  «долг», карточка подопечного с историей тренировок и оплат.
- **Оплаты**: абонементы (N занятий за сумму), остаток считается как
  «куплено − проведено − пропущено». Отмена занятие не списывает.
- **Финансы**: получено за месяц, отработано, запланировано, кто занимается в долг.

Данные хранятся в `localStorage` браузера, сервера пока нет. Кнопка «Сбросить
к демо-данным» на экране «Финансы».

## Структура

```
src/
  dev/DeviceFrame.tsx   мокап iPhone для разработки
  data/types.ts         модель: Client, Payment, Workout
  data/store.tsx        состояние + localStorage
  data/selectors.ts     расчёты: остаток занятий, долг, финансы за месяц
  screens/              экраны: Schedule, Clients, Client, Finance, формы
  components/           TabBar, Sheet (нижняя модалка), Avatar, пилюли статусов
```
